### Кроссплатформенные шрифты в рендере каруселей

**Файлы:** `src/writers/carousel_writer.py`

**Было:** Пути к шрифтам захардкожены только под Linux (`/usr/share/fonts/...`). На Windows все слайды рендерились с крошечным bitmap-шрифтом по умолчанию.

**Стало:**
- Новая функция `_find_font_file(bold)` — подбирает TTF по платформам: Windows (Arial, Segoe UI) → macOS (Arial) → Linux (DejaVu, Liberation)
- Переписаны все 3 точки загрузки шрифтов: инлайн в `render_carousel_images`, `_load_fonts()`, `_load_font_at_size()`
- `_pick_font()` упрощён: принимает один путь вместо списка

**Проверено:** Рендер постер-слайда 1080×1080 с русским текстом на Windows (Arial Bold), наложение текста подтверждено пиксель-тестом.

**Файлы:** `requirements.txt`

**Было:** `carousel_writer.py` использует numpy для плавного блюра, но в requirements его не было — на чистой машине рендер падал с ImportError.

### Фикс кодировки config.yaml (mojibake на главной)

**Файлы:** `src/api/llm.py`

**Было:** `load_config()` открывал `config.yaml` без указания кодировки — на Windows Python читал UTF-8 файл как cp1251, и тема из конфига превращалась в нечитаемую кашу (на главной в блоке «Тема» и в промптах генераций).

**Стало:** `open(p, encoding="utf-8")`. По аудиту это единственное место чтения файла без явной кодировки в проекте.

**Проверено:** Побайтовый тест ответа сервера — тема отдаётся корректным UTF-8, mojibake-байтов в странице нет.

### Карусели: плавный переход блюра (18:30)

**Файл:** `src/writers/carousel_writer.py`

**Было:** Блюр нижних 55% изображения с резкой границей. Затемнение градиентом на те же 55%.

**Стало:**
- Блюр нижних ~33% (от 67% высоты до низа)
- Плавный переход блюра на нет: зона fade ~12% высоты над границей блюра (55%→67%), линейная интерполяция через numpy
- Затемнение: мягкий переход 60%→67% (alpha 0→100), плотное 67%→100% (alpha 100→230)

**Решение:** `render_poster_slide()` теперь использует numpy для попиксельного blending оригинала и заблюренного изображения с маской плавного перехода.

```python
# Ключевая логика:
blur_edge = int(canvas_h * 0.67)       # граница схла блюра
blur_fade_zone = int(canvas_h * 0.12)  # зона плавного перехода
blur_start = blur_edge - blur_fade_zone

fade_mask = np.linspace(0, 1, fade_height)  # 0→1 плавно
blended = orig * (1 - mask) + blurred * mask
```
