# Cinema Post Writer

## Когда использовать
- Тема связана с кино, фильмами, сериалами, актёрами, режиссёрами
- Новости кино: премьеры, скандалы, рекорды, рейтинги
- Рекомендации фильмов и сериалов
- Тренды и обсуждения в соцсетях

## Процесс написания

### Шаг 1: Ресёрч (ОБЯЗАТЕЛЬНО)

Перед написанием поста — найди конкретные факты. Без ресёрча пост не пишется.

**Запросы для поиска** (выбери подходящие по теме):
- `[тема] новости 2026` — свежие новости
- `[фильм/актёр] скандал обсуждение` — если тема скандальная
- `лучшие фильмы 2026 рейтинг` — для рекомендаций
- `[тема] Reddit Threads обсуждение` — трендовые темы

**Что искать:**
- Конкретные названия фильмов/сериалов
- Цифры: рейтинги (Rotten Tomatoes, IMDb, Кинопоиск), кассовые сборы, рекорды
- Имена: режиссёр, актёры, продюсер
- Даты: когда выходит, когда вышел
- Скандалы/обсуждения: что произошло, кто что сказал
- Источники: Reddit, Threads, новостные порталы

**Критерий:** новость за последние 2 дня (проверять дату публикации). Рекомендации — только фильмы этого года, рейтинг от 7.

### Шаг 2: Отбор

Выбери ОДНУ конкретную тему для поста. Критерии:
- **Трендовость** — тема уже вызывает бурное обсуждение
- **Фактор неожиданности** — то, чего никто не ожидал
- **Эмоциональный отклик** — удивление, восторг, возмущение

### Шаг 3: Написание

**Формат: Threads**
- Не более 500 символов — стандартный пост
- Больше 500 — только для разборов по пунктам, тогда оформлять как ветку (thread)
- К посту ОБЯЗАТЕЛЬНО картинка: постер, кадр, фото актёра, скриншот рейтинга, трейлер

**Структура:**
1. **Ёмкий заголовок с хуком** — сразу цепляет, вызывает интерес дочитать
2. **Тело** — простым понятным языком, очеловеченным тоном
3. **Концовка** — забавный или логичный вопрос, побуждающий к обсуждению

**Тон:**
- Простой, понятный, очеловеченный
- Как если бы рассказывал другу классную новость
- НЕ рецензия, НЕ сухой обзор — живой рассказ

**Стилистические приёмы (из примеров автора):**
- Парадокс в заголовке: «94% на Rotten Tomatoes у фильма... про овец?»
- Личный голос: «Мне кажется, их можно понять)»
- Конкретика > абстракций: не «высокий рейтинг», а «96% на Rotten Tomatoes»
- Вопрос-концовка: «Берём в качестве идеи для свидания?»
- Ирония: мягкая, через скобочку ) или 😏
- Короткие предложения, одна мысль = одно предложение
- Не спойлерить. Не пересказ сюжета — зацепки
- Обязательно упомянуть: кто снял, кто играет, почему это важно

### ЖЁСТКИЕ ПРАВИЛА

1. **НЕТ ФАКТОВ — НЕТ ПОСТА.** Каждый пост содержит конкретные названия, цифры, имена. Никакой воды.
2. **Один пост = одна тема.** Не пытайся охватить всё в одном посте.
3. **Проверяй даты.** Новость за последние 2 дня. Не новости — не пиши.
4. **Не выдумывай.** Не знаешь рейтинг — не пиши рейтинг. Не знаешь имя — найди.
5. **Пиши на русском.**

### Выходной формат

Выдай:
1. Готовый пост (с учётом лимита 500 символов для Threads)
2. Если нужен thread — пронумеруй части: 1/3, 2/3, 3/3
3. Подсказка по картинке: что прикрепить (постер / кадр / скриншот рейтинга)
