## Известные проблемы / риски

- Веб-интерфейс не имеет авторизации — держать на `127.0.0.1`, при открытии наружу добавить basic auth
- `_next_id()` перечитывает весь JSONL-лог (O(n)) и не защищён от гонок при параллельных запросах
- LLM иногда возвращает невалидный JSON при генерации карусели (есть retry ×3; кандидат — JSON mode)
- DejaVu/Arial не покрывают все Unicode-глифы (кандидат — Noto Sans)
