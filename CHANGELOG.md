### Карусели: плавный переход блюра (18:30)

**Файл:** `src/writers/carousel_writer.py`

**Было:** Блюр нижних 55% изображения с резкой границей. Затемнение градиентом на те же 55%.

**Стало:**
- Блюр нижних ~33% (от 67% высоты до низа)
- Плавный переход блюра на нет: зона fade ~12% высоты над границей блюра (55%→67%), линейная интерполяция через numpy
- Затемнение: мягкий переход 60%→67% (alpha 0→100), плотное 67%→100% (alpha 100→230)

**Решение:** `render_poster_slide()` теперь использует numpy для попиксельного blending оригинала и заблюренного изображения с маской плавного перехода.

```python
# Ключевая логика:
blur_edge = int(canvas_h * 0.67)       # граница схла блюра
blur_fade_zone = int(canvas_h * 0.12)  # зона плавного перехода
blur_start = blur_edge - blur_fade_zone

fade_mask = np.linspace(0, 1, fade_height)  # 0→1 плавно
blended = orig * (1 - mask) + blurred * mask
```
